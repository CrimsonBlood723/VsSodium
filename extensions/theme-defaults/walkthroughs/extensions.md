# An optional extension starter pack

VsSodium keeps its base install lean. Install only the language tools you use, and disable or uninstall extensions you no longer need.

- [Rust Analyzer](vscode:extension/rust-lang.rust-analyzer) for Rust language support
- [Python](vscode:extension/ms-python.python) for Python projects
- [ESLint](vscode:extension/dbaeumer.vscode-eslint) for JavaScript and TypeScript linting
- [Prettier](vscode:extension/esbenp.prettier-vscode) for code formatting
- [Docker](vscode:extension/ms-azuretools.vscode-docker) for container projects

These are recommendations, not bundled extensions. Review publisher and permissions before installing, and add tools one at a time if memory is limited.
